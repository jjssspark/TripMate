# TripMate

AI가 제안하고 코드가 검증하는 여행 일정 설계 서비스

---

### 📖 내용

- Gemini가 장소 후보를 내면 Kakao API로 실재 여부를 검증. 날짜 배정(k-means)·동선(TSP)·시각 배치는 코드가 계산
- 중복과 동선을 프롬프트가 아니라 코드가 강제 — 후보 제안 → 실재 검증 → 날짜 배정 → 순서 결정 → 시각 배치 → 설명, 6단계 분리
- 실패 시 가짜 일정을 내보내던 폴백 제거. 대신 원인별 안내 — 장소 부족 422, AI 한도 소진 429(재시도 시각 포함)
- 무료 한도(모델당 하루 20회) 안에서 돌도록 호출 축소 — 일정 1건당 4회 → 2회
- 공유 링크(/trip/:id), PWA 설치, 카테고리별 목업 이미지

### 🙋‍♂️ 역할

1인 개발. 팀 프로젝트 제출(2026-06-17) 후 개인 저장소로 이전해 전 영역 단독 고도화.

- 일정 생성 파이프라인 재설계 — 단일 LLM 호출 → 6단계 검증 구조
- 외부 API 제약 대응 — thinking 비활성화, 타임아웃 예산 재배분, 호출 횟수 최적화
- React Query 전환, 공유 링크, Places 사진 프록시(키를 클라이언트에 노출하지 않는 서버 경유)
- 문서화 — 트러블슈팅 22건 기록, 대표 5건·ADR 5건 별도 정리
